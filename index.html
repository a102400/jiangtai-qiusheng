怎么把它部署上线

当前这份页面是纯静态单文件，零依赖、零构建，任何静态托管都能跑。下面是三条最省事的上线路线。

路线 A：Vercel（推荐）

  1. 把 index.html 放进任意文件夹，或直接推到 GitHub 仓库。
  2. 打开 vercel.com → Add New → Project → 导入该仓库。
  3. 框架预设选 Other / Static，构建命令留空，输出目录留空。
  4. 点 Deploy，约 30 秒拿到 xxx.vercel.app 域名。
  5. 如需自定义域名：Settings → Domains → 添加后按提示改 DNS。

路线 B：Netlify / GitHub Pages

  1. Netlify：把文件夹直接拖到 app.netlify.com/drop，即时上线。
  2. GitHub Pages：仓库 Settings → Pages → Source 选 main / root。
  3. 两者都免费提供 HTTPS 与二级域名，适合校内演示。
  4. 注意：Pages 仓库需公开（免费版），敏感信息勿入库。

路线 C：升级成真全栈

  1. 接真实 AI：把项目迁到 Next.js，用 API Routes 做后端代理。
  2. 在 .env.local 写 DEEPSEEK_API_KEY，绝不下发到浏览器。
  3. Whisper 转写走服务端，避免密钥泄露与跨域问题。
  4. 后端部署 Render / Railway，前端仍用 Vercel。

推荐技术栈组合

前端Next.js 14（App Router）+ Tailwind CSS + shadcn/ui —— 组件全、出图快
后端优先 Next.js API Routes（省一套部署）；需要 Python AI 生态时再上 FastAPI
