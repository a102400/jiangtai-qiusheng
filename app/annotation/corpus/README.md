# 语料投放处

把试讲转写稿放进本目录（支持 `.txt` `.md` `.srt` `.vtt` `.json`），然后：

```bash
node scripts/build-annotation-set.js --input annotation/corpus --n 200
```

## 要求

- 单份 1500 字以上，或 3–5 份拼接；低于 1000 字抽不满 200 句
- **保留口语原样，不要清洗**。「嗯」「那个」「好」是反馈类编码的证据，删掉就是篡改数据
- 有学生发言就保留 `生：` 标记
