# 讲台求生 · 3 分钟演示视频录制指引

三种方式，推荐顺序：**① 页内一键录制 → ② OBS → ③ 系统录屏**。

---

## ① 页内一键录制（最快，零安装）

1. 用 **Chrome / Edge** 打开线上链接，点右上角 **🎬 路演**。
2. 底部选择节奏：
   - **标准 3:00**：6 段停留合计 180 秒，和真人讲稿同步，适合正式提交。
   - **快剪 60s**：合计约 70 秒，适合发朋友圈 / 群聊预览。
3. 点 **◉ 录制整场** → 浏览器弹窗选择「**当前标签页**」（不是整个屏幕，避免泄露桌面）。
4. 勾选 **分享音频**（如果想录讲解声；不勾则只有画面）。
5. 全程自动：系统会按 6 个分镜依次执行并停留，**最后自动停止并下载** `讲台求生-路演-3min-<时间戳>.webm`。
6. 按钮文案变回 `◉ 录制整场` 即完成，同目录下会多一个 webm 文件。

> 注意：录制期间不要切标签页，否则录到的是空白。
> 首次点击需要授权屏幕共享，选「整个标签页 / 此标签页」。

### 想加旁白怎么办

页内录制只录系统声音。若要真人讲解，用方式 ② 或 ③，边点「执行」边说话。

---

## ② OBS Studio（推荐用于正式提交）

| 项 | 建议值 |
|---|---|
| 场景 | 窗口采集 → 选浏览器窗口（不要采集整个桌面） |
| 分辨率 | 1920×1080（画布与输出一致，避免缩放模糊） |
| 帧率 | 30 fps 足够（页面动效不激烈） |
| 编码 | x264，CQP 20 或 码率 6000 Kbps |
| 音频 | 麦克风 48kHz，噪声抑制开 |
| 格式 | mp4（录完直接可用） |

操作顺序：先点 OBS「开始录制」→ 再点页面「🎬 路演」→ 按脚本节奏点各步「执行」→ 讲完点停止。

---

## ③ 系统录屏（兜底）

- **Windows**：`Win + Alt + R`（Xbox Game Bar，录当前窗口）或 `Win + G` 调面板。
- **macOS**：`Cmd + Shift + 5` → 录制所选窗口 + 麦克风。

---

## 后期建议（10 分钟内能做完）

1. **片头 3 秒**：黑底白字「讲台求生 · 师范生 AI 试讲教练」+ 一行副标题「讲一次，当场告诉你哪里会翻车」。
2. **加速无信息段落**：等接口返回的 2–5 秒可以 1.5× 加速或直接切掉。
3. **关键帧加字幕**：52 分、等待 0.5 秒（红色）、压力条、树洞回信——这四处各加一行字幕，让无声播放也能看懂。
4. **结尾 5 秒**：二维码（页面「生成海报」里的二维码可直接截图）+ 一句话价值「我们卖的不是评分，是上台之前的第二次机会」。
5. 导出：H.264 / 1080p / 8–12 Mbps，文件控制在 60 MB 以内，方便微信发送。

## 录制检查清单

- [ ] 浏览器窗口宽度 ≥ 1280px（移动端布局不适合拍视频）
- [ ] 提前跑一次「▷ 自动演示」预热，确保接口和模型都活着
- [ ] 画面里不出现自己的昵称/手机号（榜单和树洞会显示本机数据）
- [ ] 声音电平 -12dB 左右，不要爆音
- [ ] 录完立刻回放一遍，确认 6 个分镜都完整
